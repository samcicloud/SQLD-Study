# Practice

SQLD는 Oracle 문법을 기준으로 출제되는 경우가 많아서 Oracle 환경에서 실습하는 것을 추천합니다.

## 실습 환경 (택 1)
- [Oracle Live SQL](https://livesql.oracle.com): 설치 없이 브라우저에서 실행
- Oracle Database Free (Docker 또는 로컬 설치) + SQL Developer / DBeaver

## 사용 방법
1. [schema.sql](schema.sql)을 실행해 `DEPT`, `EMP` 테이블과 샘플 데이터를 만듭니다.
2. [exercises.sql](exercises.sql)의 문제를 풀고 답 쿼리와 결과를 아래에 기록합니다.
3. 직접 만든 쿼리는 주제별 파일로 저장합니다 (예: `window-functions.sql`).
