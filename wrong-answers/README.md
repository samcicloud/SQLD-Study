# 오답노트

틀린 문제는 같은 실수를 반복하지 않도록 **왜 틀렸는지**를 중심으로 기록합니다.
회차나 주제별로 파일을 나눠 주세요 (예: `mock-01.md`, `window-functions.md`).

## 오답 템플릿

```markdown
### [과목 / 주제] 문제 요약

- 출처: (기출 OO회 / 모의고사 / 교재 p.OO)
- 내 답: ② / 정답: ④
- 틀린 이유: (개념 부족 / 실수 / 헷갈림)
- 핵심 개념:
- 확인 쿼리: (가능하면 직접 실행해 본 쿼리와 결과)
- 다시 풀기: [ ] 1회차  [ ] 2회차
```
