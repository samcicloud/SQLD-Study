# 2과목. SQL 기본과 활용

주제별로 파일을 하나씩 만들어 정리하세요. 예제 쿼리는 [practice/](../practice/)의 스키마로 직접 실행해 보세요.

## 1장. SQL 기본
- [ ] 관계형 데이터베이스 개요
- [ ] SELECT 문, 연산자, WHERE 절
- [ ] 함수 (문자 / 숫자 / 날짜 / 변환 / NULL 관련: NVL, NULLIF, COALESCE)
- [ ] GROUP BY, HAVING 절, 집계 함수
- [ ] ORDER BY 절, SELECT 문 실행 순서
- [ ] 조인 (EQUI / Non-EQUI)
- [ ] 표준 조인 (INNER, NATURAL, USING, ON, CROSS, OUTER)

## 2장. SQL 활용
- [ ] 서브쿼리 (단일행 / 다중행 / 연관, 인라인 뷰, 스칼라 서브쿼리)
- [ ] 집합 연산자 (UNION, UNION ALL, INTERSECT, MINUS)
- [ ] 그룹 함수 (ROLLUP, CUBE, GROUPING SETS, GROUPING)
- [ ] 윈도우 함수 (RANK, DENSE_RANK, ROW_NUMBER, LAG/LEAD, 윈도우 범위)
- [ ] Top N 쿼리 (ROWNUM, FETCH FIRST)
- [ ] 계층형 질의 (START WITH, CONNECT BY, PRIOR)와 셀프 조인
- [ ] PIVOT / UNPIVOT
- [ ] 정규 표현식

## 3장. 관리 구문
- [ ] DML (INSERT, UPDATE, DELETE, MERGE)
